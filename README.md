# AOU Hub — iPhone

Releases of the AOU Hub iPhone app (SwiftUI, built with [xtool](https://github.com/xtool-org/xtool)).

Download the latest **AOUHub.ipa** from [Releases](../../releases/latest) and install it
with Sideloadly or AltStore using your own Apple ID. Requires iOS 17+.

Source mirror of `ios/` and `shared/` from the AOU Hub monorepo; see `ios/README.md`.
